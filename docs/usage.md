Annealed Cu starts at conductivity 5.8e7 S/m, εr=μr=1 and relaxation time 0; these properties remain editable. Opening an older case preserves its active coating definitions and renames the standard Cu preset to Annealed Cu.

Extract `ARCS_v0.6.7.zip`, enter `arcs_v0_6_7`, create a Python 3.10+ virtual environment and install:


The default bare circular material is copper with σ=5.8e7 S/m. Output directories contain signed impedance/tensor CSV, plots, geometry and metadata. The default sweep is logarithmic with 100 points from 10 Hz to 10¹³ Hz; shorter bands and point counts can be requested explicitly. Fields require positive frequencies; the requested audit floor is 10 Hz.

`--beta` overrides the saved dimensionless β. `--roughness-rms-um` enables the Gaussian wall-depth model with height in micrometres, independent of drawing units. `--roughness-slices` controls material-profile subdivision; `--roughness-extent` controls truncation in RMS heights. New profiles retain 32 slices and extent 5. Field solving rejects extents above 5 because an extended-tail audit failed. `--longitudinal-only` skips transverse derivatives. A 32-slice bare rough wall has 33 boundary meshes and is slower than a bare wall.

## Axial pipe length

Supply `--pipe-length-m 5` when running a uniform 5 m pipe, or create
`case.make_solver(pipe_length_m=5.0)` in Python. The parameter always uses metres,
even if the cross-section drawing uses millimetres. Longitudinal and constant
terms become Ohm; dipolar/quadrupolar coefficients become Ohm/m. All components
are multiplied by the same length. Omitting length selects a **1.0 m pipe** with total-pipe output. Explicit
`--per-unit-length` (CLI) or `pipe_length_m=None` (Python) selects per-metre output.
Plots and CSV generated by the runner use the selected units.

For Python longitudinal plots, pass `per_unit_length=False` for already scaled
totals; this option changes labels only. Transverse plots read the length from
the result. Use a reference in the same normalization. The raw `MaxwellSolver`
backend continues to return per-length values. For an existing explicitly per-length
transverse result, `response.for_pipe_length(5.0)` integrates its four fields
once and records the length. No entrance/exit effects are introduced.

Draw primitives/polygons, enter coordinates, import planar DXF, or use crop/Boolean tools. The first material is vacuum. Assign finite positive conductivity to conducting regions. For an ideal wall select **PEC** in the **Exterior** material dropdown; PEC has no conductivity parameter. Smooth coating outlines can have independent shapes and varying thickness.

**View / edit material properties** shows fixed vacuum, PEC and air information. Select the vacuum row to inspect its fixed σ=0 S/m, εr=μr=1 and relaxation time=0. The air preset uses those same ideal parameters; Air as the exterior is supported for beta<1, with smooth conducting layers. The beta=1 open-exterior limit and finite insulating gaps remain unsupported. PEC is an exact tangential-E=0 termination. Bare PEC has RW=0 and retains finite-beta indirect space charge. At β=1 the uniform-pipe impedance is zero. Finite coatings can precede PEC; the thin-coating THz example in notebook 06 shows why mesh convergence remains necessary. Do not combine PEC with conductivity-gradient roughness.

**Generate / update mesh** opens **Mesh only** with nodes visible. Select **Inspect mesh** and click a panel, or choose its boundary and number below the canvas. Use **Zoom to layer meshes** for thin interfaces. Roughness material meshes are drawn/exported as well. Save the JSON case and run it with the numerical runner. Numerical frequency sweeps use Python.

Roughness aperture coordinates describe the air-side plane; the mean surface is `extent_sigma*Rq` outward. Profiles default to 5Rq and 32 slices; explicit saved settings are preserved. A smooth mean-surface aperture and rough air-side aperture are different reference geometries.

## Output meaning

By default, output is for a 1.0 m uniform pipe: longitudinal values are Ω and transverse coefficients are Ω/m. In explicit per-unit-length mode, longitudinal values are Ω/m. Dipolar and quadrupolar coefficients are Ω/m² per unit pipe length and multiply source/witness offsets respectively. The solver reports **RW + indirect space charge**, relative to free space. Direct space charge is excluded. Select `component='resistive_wall'` or `component='indirect_space_charge'` to separate contributions. Plots and CSV show signed Im directly.

The material model retains Maxwell displacement current, permeability and optional Drude conductivity. There is no MQS backend or local planar wall solver. Open Air/Vacuum exteriors require beta<1. Finite insulating gaps, general dielectric/radiating exteriors, and longitudinally varying rough geometry remain unsupported. The roughness approximation smooths conductivity in wall depth.

Wake conversion needs an explicit DC entry, a suitable uniform frequency grid and sufficient bandwidth. The notebook's 0–10 THz demonstration is a finite-band reconstruction, not a converged point wake. `s=βct` converts time to distance. Read [wakes.md](wakes.md) for transform signs and endpoints.

## Wall components and linear axes

```python
parts = solver.transverse_components(f)
response = parts['wall']                  # default: RW + indirect SC
rw = parts['resistive_wall']
image = parts['indirect_space_charge']
from arcs.plotting import plot_longitudinal
figure = plot_longitudinal(f, response.longitudinal, xscale='linear', yscale='linear')
```

The CLI supports `--component wall`, `--component resistive_wall` and `--component indirect_space_charge`. `wall` is the default. ARCS v0.5.x spectra must be conjugated once to adopt the new convention; do not negate Im again in plots. The legacy wake adapter is `convention='arcs_legacy'`.

For finite-beta wall spectra use `impedance_to_wake(..., causal=False)` on a uniform frequency grid with justified DC values. This returns a signed-time waveform using both complex components. The original causal DCT/DST kernels remain available for spectra whose one-sided causality has been established.
